# 小红书舆情监控 · F 界面预览

这是使用样例数据的 UI 预览。可体验新建监控、继续监控、模拟登录、任务进度和结果状态。网站采集、账号登录、AI 请求及 Excel 输出属于正式版功能。预览可离线运行。

1. 将 ZIP 解压到一个独立目录。
2. 在浏览器的扩展管理页启用开发者模式，选择「加载已解压的扩展程序」，定位到包含 `manifest.json` 的目录。 [华为浏览器](https://consumer.huawei.com/cn/support/content/zh-cn16082289/) · [Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)
3. 在扩展菜单选择「小红书舆情监控 · F 界面预览」，点击「打开界面预览」。

已在 Windows 上的 Chromium 158 验证。鸿蒙电脑和华为浏览器实机待验证。

## F interface preview

This offline demo uses sample data for creating or resuming a task, simulated sign-in, progress and results. The production release handles website collection, account sign-in, AI requests and Excel export.

Extract this ZIP. In a browser that supports unpacked Manifest V3 extensions, enable Developer mode and select the folder that contains `manifest.json`. Open **小红书舆情监控 · F 界面预览** from the extensions menu and click **打开界面预览**.

Verified with Chromium 158 on Windows. Native HarmonyOS PC and HUAWEI Browser testing is pending.
