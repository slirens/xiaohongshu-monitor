## F 界面预览 · F UI Preview

试用无封面的 F 设计。界面按「设置任务、执行监控、查看报告」呈现，用样例体验新建和续查、关键词与日期、登录提示、后台状态以及进度小窗。预览界面为简体中文。实际监控、AI 分析和 Excel 导出请使用 [v1.0.8 正式版](https://github.com/slirens/xiaohongshu-monitor/releases/tag/v1.0.8)。

Explore the cover-free F design. The preview walks through setup, monitoring, and report review, including continuation, sign-in prompts, background status, and the compact progress window. It uses built-in sample data and a Simplified Chinese interface. For live monitoring, AI analysis, and Excel export, use the [stable v1.0.8 release](https://github.com/slirens/xiaohongshu-monitor/releases/tag/v1.0.8).
